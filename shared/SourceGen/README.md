# Shared Source Generator Utilities

This directory contains shared code for Roslyn source generators used across all Pragmatic.Design modules.

> **Important**: This code is distributed via linked files, NOT as a NuGet package.
> Generator projects automatically include these files via `Directory.Build.props`.

## Quick Start

When creating a new source generator:

```csharp
using Pragmatic.SourceGen;

[Generator]
public class MyModuleSourceGenerator : IIncrementalGenerator
{
    public void Initialize(IncrementalGeneratorInitializationContext context)
    {
        // Use AttributeNames constants (hides ugly generic syntax)
        var provider = context.SyntaxProvider.ForAttributeWithMetadataName(
            AttributeNames.MapFrom,  // "Pragmatic.Mapping.MapFromAttribute`1"
            predicate: GeneratorHelpers.IsClassOrRecord,  // Pre-built predicates
            transform: static (ctx, ct) => TransformToModel(ctx, ct));

        context.RegisterSourceOutput(
            provider.Where(static m => m is not null),
            static (spc, model) => Generate(spc, model!));
    }

    private static MyModel? TransformToModel(
        GeneratorAttributeSyntaxContext context,
        CancellationToken ct)
    {
        if (context.TargetSymbol is not INamedTypeSymbol symbol)
            return null;

        // Use SymbolExtensions for common operations
        return new MyModel
        {
            Namespace = symbol.GetNamespaceOrEmpty(),
            TypeName = symbol.Name,
            FullName = symbol.GetFullyQualifiedName()
        };
    }

    private static void Generate(SourceProductionContext context, MyModel model)
    {
        // Option 1: CSharpBuilder for simple generation
        var builder = new CSharpBuilder();
        builder
            .AutoGeneratedHeader()
            .Namespace(model.Namespace)
            .Line("public partial class " + model.TypeName)
            .Block(b => b
                .Line("// Generated code here")
            );

        context.AddSource(
            GeneratorHelpers.GetHintName(model.TypeName),
            builder.Build());

        // Option 2: CSharpTemplate for complex generation (inheritance-based)
        // var template = new MyTemplate(model);
        // var artifact = template.RenderOutput();
        // context.AddSource(artifact.FileName, artifact.Content);
    }
}

// Model must be a record for proper caching
internal record MyModel
{
    public required string Namespace { get; init; }
    public required string TypeName { get; init; }
    public required string FullName { get; init; }
}
```

## Detailed API Reference

### AttributeNames

Hides the ugly backtick syntax for generic attributes in metadata names:

```csharp
// Without AttributeNames - hard to read
context.SyntaxProvider.ForAttributeWithMetadataName(
    "Pragmatic.Mapping.MapFromAttribute`1",  // What's `1?
    ...);

// With AttributeNames - clear and maintainable
context.SyntaxProvider.ForAttributeWithMetadataName(
    AttributeNames.MapFrom,  // Self-documenting
    ...);

// For custom generic attributes
var name = AttributeNames.WithArity("MyNamespace.MyAttribute", 2);  // "MyNamespace.MyAttribute`2"
```

### GeneratorHelpers

Pre-built predicates for `ForAttributeWithMetadataName`:

```csharp
// Predicates (first parameter of ForAttributeWithMetadataName)
GeneratorHelpers.IsClass           // ClassDeclarationSyntax
GeneratorHelpers.IsRecord          // RecordDeclarationSyntax
GeneratorHelpers.IsStruct          // StructDeclarationSyntax
GeneratorHelpers.IsClassOrRecord   // Either class or record
GeneratorHelpers.IsTypeDeclaration // Any type (class, struct, record, interface)
GeneratorHelpers.IsMethod          // MethodDeclarationSyntax
GeneratorHelpers.IsProperty        // PropertyDeclarationSyntax

// File name helpers
GeneratorHelpers.GetHintName("UserDto");           // "UserDto.g.cs"
GeneratorHelpers.GetHintName("UserDto", "Mapper"); // "UserDto.Mapper.g.cs"
```

### SymbolExtensions

Extension methods for working with Roslyn symbols:

```csharp
INamedTypeSymbol symbol = ...;

// Namespace
symbol.GetNamespace();           // "MyNamespace.SubNs" or null
symbol.GetNamespaceOrEmpty();    // "MyNamespace.SubNs" or ""

// Type names
symbol.GetFullyQualifiedName();  // "global::MyNamespace.MyClass"
symbol.GetFullName();            // "MyNamespace.MyClass" (no global::)

// Attributes
symbol.HasAttribute("My.AttributeName");
symbol.GetAttribute("My.AttributeName");  // AttributeData?

// Properties
symbol.GetProperties();                   // All properties
symbol.GetProperties(includeBase: true);  // Including inherited

// Nullability
property.IsNullable();  // bool - considers nullable annotations
```

### CSharpBuilder

Fluent builder for generating C# code with automatic indentation:

```csharp
var builder = new CSharpBuilder();

builder
    .AutoGeneratedHeader()    // Standard "do not edit" header
    .NullableEnable()         // #nullable enable
    .Line()
    .Namespace("MyNamespace")
    .Line()
    .ClassBlock("public partial", "MyClass", "BaseClass, IInterface", b => b
        .Line("private readonly int _value;")
        .Line()
        .Line("public int Value => _value;")
    );

string code = builder.Build();  // Returns formatted C# string
SourceText text = builder.BuildSourceText();  // For AddSource
```

**Block Methods** (auto-handle braces and indentation):
- `Block(action)` - Generic block with `{ }`
- `ClassBlock(modifiers, name, baseList, action)` - Class declaration
- `MethodBlock(signature, action)` - Method with body
- `IfBlock(condition, action)` - If statement
- `RegionBlock(name, action)` - #region / #endregion

### CSharpTemplate

Abstract base class for complex, inheritance-based code generation:

```csharp
internal class UserDtoTemplate : CSharpTemplate
{
    private readonly UserModel _model;

    public UserDtoTemplate(UserModel model) => _model = model;

    public override Artifact RenderOutput()
    {
        RenderFile();
        return new Artifact($"{_model.TypeName}.g.cs", ToSourceText());
    }

    public override void RenderFile()
    {
        Header();
        Using("System");
        Line();
        StartNamespace(_model.Namespace);
        {
            StartClass(AccessModifier.Public, isPartial: true, _model.TypeName);
            {
                RenderProperties();
                RenderMethods();
            }
            EndClass();
        }
        EndNamespace();
    }

    private void RenderProperties() { ... }
    private void RenderMethods() { ... }
}

// Usage in generator
var template = new UserDtoTemplate(model);
var artifact = template.RenderOutput();
context.AddSource(artifact.FileName, artifact.Content);
```

## Best Practices

### 1. Always Use Record for Models

```csharp
// Records implement IEquatable correctly for caching
internal record MyModel
{
    public required string TypeName { get; init; }
    public ImmutableArray<PropertyModel> Properties { get; init; }
}

// Classes break incremental caching!
internal class MyModel  // DON'T DO THIS
{
    public string TypeName { get; set; }
}
```

### 2. Use ForAttributeWithMetadataName

```csharp
// CORRECT - Most efficient, filtered by compiler
context.SyntaxProvider.ForAttributeWithMetadataName(
    AttributeNames.MapFrom,
    predicate: GeneratorHelpers.IsClassOrRecord,
    transform: ...);

// AVOID - Less efficient
context.SyntaxProvider.CreateSyntaxProvider(
    predicate: ...,  // Runs on ALL syntax nodes
    transform: ...);
```

### 3. Handle Cancellation

```csharp
private static MyModel? TransformToModel(
    GeneratorAttributeSyntaxContext context,
    CancellationToken ct)
{
    ct.ThrowIfCancellationRequested();  // Early exit

    // For expensive operations
    foreach (var prop in properties)
    {
        ct.ThrowIfCancellationRequested();
        ProcessProperty(prop);
    }
}
```

### 4. Diagnostics in Assigned Range

Each module has a dedicated diagnostic ID range (see `docs/diagnostics.md`):

```csharp
// PRAG0300-0399 is Mapping's range
public static readonly DiagnosticDescriptor MissingPartial = new(
    id: "PRAG0300",  // Within range
    title: "Missing partial modifier",
    messageFormat: "Type '{0}' must be partial to use [MapFrom]",
    category: "Pragmatic.Mapping",
    defaultSeverity: DiagnosticSeverity.Error,
    isEnabledByDefault: true);
```

## How Linking Works

In `Directory.Build.props`:

```xml
<!-- Auto-include shared SourceGen code for generators -->
<ItemGroup Condition="'$(IsGenerator)' == 'true' AND Exists('$(SharedSourceGenPath)')">
  <Compile Include="$(SharedSourceGenPath)**\*.cs" LinkBase="Shared" />
</ItemGroup>
```

Files appear in Solution Explorer under `Shared/` virtual folder but are compiled directly into each generator assembly (no runtime dependency).

## Polyfills

`Polyfills.cs` provides netstandard2.0 compatibility for:
- `init` keyword (`IsExternalInit`)
- `required` keyword (`RequiredMemberAttribute`, `CompilerFeatureRequiredAttribute`)
- `[SetsRequiredMembers]` attribute

These are automatically included and conditionally compiled (`#if NETSTANDARD2_0`).
