# scripts

The repository's tooling, in Node (no dependencies beyond Node itself). Run everything from the
repository root. Each script's header says what it does and why; this page says which one to reach for.

## The gate

| Script | What it does |
|---|---|
| [`check.mjs`](check.mjs) | **The** gate, the same locally and in CI: a clean build with warnings as errors, every ratchet, and the test suites. `--tier fast` (changed modules), `full` (every hermetic suite), `aot` (the Native AOT smoke applications), `docker` (the container suites, one at a time), `all` (all of them), `verify` (only that every path the CI names exists). `--only <substring>` runs the matching suites and says it is not the gate. [docs/TESTING.md](../docs/TESTING.md) explains how to read it. |

`check.mjs` calls most of the scripts below. They also run on their own, printing the names behind the
numbers the gate only counts.

## Keeping generated files in step

Each rewrites a file from its sources; `--check` changes nothing and fails when they differ. The gate runs
the `--check` form.

| Script | What it keeps in step |
|---|---|
| [`sync-diagnostics.mjs`](sync-diagnostics.mjs) | [`docs/diagnostics.md`](../docs/diagnostics.md), from every `DiagnosticDescriptor` in the repository. Also reports two descriptors with one ID. |
| [`site-diagnostics.mjs`](site-diagnostics.mjs) | That every declared diagnostic has a row on the site's diagnostics reference. |
| [`sync-slnx-docs.mjs`](sync-slnx-docs.mjs) | The `/docs/` solution folders of every `.slnx`, from the markdown on disk. |
| [`accept-snapshots.mjs`](accept-snapshots.mjs) | Accepts generator snapshots whose diff is purely cosmetic (a licence header, a generator version line), and lists every other one for a human. |
| [`native-stamp.mjs`](native-stamp.mjs), [`refresh-native.mjs`](refresh-native.mjs) | The native binaries under `Pragmatic.Documents/runtimes/` and `Pragmatic.Imaging/runtimes/`: `refresh-native` rebuilds them from the Rust source, stamped with its hash; the gate refuses a binary whose stamp is not the current source. `--linux` builds in Docker. |

The site's module pages are generated by [`site/scripts/sync-docs.mjs`](../site/scripts/sync-docs.mjs).

## Measures

Each prints what the gate counts, with the names.

| Script | What it measures |
|---|---|
| [`attribute-readers.mjs`](attribute-readers.mjs) | Declared attributes nothing reads, and their properties nothing names. |
| [`example-coverage.mjs`](example-coverage.mjs) | Which public attributes the example applications write, module by module. |
| [`skill-coverage.mjs`](skill-coverage.mjs) | Which attributes the agent skills in `marketplace/` never mention. |
| [`silent-drops.mjs`](silent-drops.mjs) | Generator transforms that discard a declaration without reporting it. |
| [`host-provided-contracts.mjs`](host-provided-contracts.mjs) | Services that depend on a contract only a host registers, without saying so. |
| [`check-reachability.mjs`](check-reachability.mjs) | Types nothing uses. |
| [`generated-code-stats.mjs`](generated-code-stats.mjs) | How much code the generators write for an example, next to the code written by hand. |
| [`reference-app-packages.mjs`](reference-app-packages.mjs) | Which runtime packages the reference applications reach. |
| [`supply-chain.mjs`](supply-chain.mjs) | A CycloneDX SBOM per shipped package, and a scan for known vulnerabilities. Run by the gate. |
| [`package-markdown-links.mjs`](package-markdown-links.mjs) | That every relative link in a package's markdown resolves inside the package. |

## Before a change goes out

| Script | What it does |
|---|---|
| [`breaking-change-check.mjs`](breaking-change-check.mjs) | Reads a diff and flags what could break a public contract. |
| [`publication-scan.mjs`](publication-scan.mjs) | What a publication review can decide by looking: comments not in English, personal data, links into unpublished folders, work marked as not done. |
| [`publish-local.mjs`](publish-local.mjs) | A clean Release build, pack and push of every package to a local feed. See [docs/howto/local-nuget-server.md](../docs/howto/local-nuget-server.md). |
| [`attest-published.mjs`](attest-published.mjs) | Fetches a release's packages as nuget.org serves them and checks each is the build plus nuget.org's signature, for `attest-published.yml` to attest. |

## `lib/`

Code the scripts share: a C# line classifier (`csharp-lines`), the attribute and example-coverage
readers, the failure record a red run leaves in `artifacts/gate/`, what the gate may clean up on this
machine (`gate-ownership`), one gate run at a time (`run-lock`), and a bounded pool of child processes
(`spawn-async`). Each `*.test.mjs` next to a script is its test, run with `node --test`.
